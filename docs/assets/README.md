# README visual assets

These files are bundled locally so the project README does not depend on an image-hosting service.

| File | Source |
| --- | --- |
| `readme-banner.svg` | Original project artwork using the application’s graphite and blue palette. This is a product illustration, not an application screenshot. |
| `backup-screen.png` | Unmodified screenshot of FCS Mobile 2.8.1 on Android, showing backup status. |
| `settings-screen.png` | Unmodified screenshot of FCS Mobile 2.8.1 on Android, showing connection settings with the key masked. |

The screenshots deliberately exclude personal gallery content and visible connection keys. Documentation screenshots should follow the same rule. These assets are separate from application resources.
